# Accesibilidad web

Objetivo operativo: WCAG 2.2 AA razonable, sin afirmar certificación.

- Landmarks y jerarquía de headings coherentes por ruta.
- Links y botones semánticos; un destino inexistente no se representa como enlace.
- Labels persistentes, autocomplete útil, `aria-live` para resultados y mensajes
  de error humanos.
- Foco visible con contraste suficiente y orden de teclado lógico.
- Menú móvil con `aria-expanded`, Escape, contención de foco, retorno al disparador
  y bloqueo de scroll mientras está abierto.
- Selector de tema con nombre, estado y opciones accesibles.
- Targets de al menos 44 px cuando sea posible y contenido válido con zoom/texto
  largo.
- Alt vacío en imágenes decorativas y descripción cuando aporta información.
- `prefers-reduced-motion` conserva todo el contenido visible.
